# 审计日志单条与批量删除实施计划

**Goal:** 操作日志和登录日志均支持单条删除及当前页勾选批量删除。

**Architecture:** 复用现有分类和数据范围查询，在事务内锁定并校验全部目标后删除。两类日志分别使用新的 `log:delete`、`log:security-delete` 权限，旧只读兼容授权不升级为删除授权。每批 1–100 个不重复正整数 ID，禁止空请求清空，记录实际删除数量和目标 ID。

**Tech Stack:** Go/Hertz/GORM/MySQL、Vue 3/Element Plus/TypeScript。

- [x] 服务与测试：在 `backend/internal/service/admin/adminlog/delete.go` 增加校验和事务删除；扩展现有 SQL fixture，覆盖权限、分类、数据范围、缺失目标、数据库失败和事务回滚。
- [x] HTTP 与权限：增加两类日志的单条/批量 DELETE 路由、JSON 请求 DTO、错误响应和审计信息；更新权限目录、SQL 迁移、Swagger 与文档。迁移仅注册权限，不给历史角色自动授权。
- [x] Admin：在日志控制器增加选择、删除确认、防重入、错误和分页回退；在列表增加选择列、单条删除与批量按钮。保留当前筛选，切换范围清空选择，过期确认不发送删除请求。
