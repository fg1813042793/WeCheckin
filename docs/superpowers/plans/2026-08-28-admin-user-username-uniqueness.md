# 管理后台用户名唯一性优化计划

## 目标

管理后台新增或编辑用户时，统一规范化用户名，并在后端拒绝与其他用户重复的用户名。错误信息直接复用管理后台全局请求提示展示。

## 约束

- 用户名保存前去除首尾空格，空字符串不可保存。
- 新增用户时，用户名不能与任意现有用户重复。
- 编辑用户时允许保留当前用户名，但不能改为其他用户已有的用户名。
- 唯一性校验不受当前管理员数据权限影响，避免与不可见用户产生重复。
- 本次不修改手机号规则，也不增加数据库唯一索引，避免历史同名数据导致迁移失败。

## 实施步骤

1. 为用户名规范化与三条用户写入路径补充失败测试。
2. 在用户服务层增加统一规范化函数和事务内唯一性校验。
3. 新增、普通编辑、管理员数据范围编辑均接入统一校验。
4. 管理后台提交前使用规范化后的用户名，后端错误通过全局提示展示。
5. 运行后端定向测试和管理后台构建验证。
