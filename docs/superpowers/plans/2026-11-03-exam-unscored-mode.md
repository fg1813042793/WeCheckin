# Exam unscored mode

用户确认的任务：考试设计器“计分方式”增加明确的“不计分”选项。

契约：`examScoreMode: "none"` 为显式不计分；空值保持历史兼容规则。显式 none 优先于题型、旧题目分值、参考答案、选项/填空分值，不进入评分结果、总分、正确题数或人工评分队列。题目仍保留在答题表单、提交答案和导出中，必填/逻辑/导航规则继续执行。存量答卷的已保存成绩不重算、不回写。

实施：

- Admin 设计器新增选项并隐藏答案/分值设置，清空选择也显式设为 none；总分忽略 none；共享题目类型支持枚举。
- 后端 schema grading plan 和评分引擎忽略 none，保留其余题目的原始 ordinal；题库试卷路径尊重题目 schema 的 none。答案存储仍使用原完整 answers。
- 前端答题页、答卷详情和 uni-app 的分值展示忽略 none，仍显示题目及回答；存储结果优先，不因后来编辑题目而改写历史成绩显示。
- 导出未计分题标记“不计分”，不出现“待人工评分”或借用相邻题成绩；修正/覆盖评分映射测试，兼容题库 ID 与 schema ordinal。
- 先补涵盖残留分值、混合题型、schema ordinal、全部不计分、快照/人工批改与导出的回归，再实现。
- 验证 Backend 相关 Go 测试及全量；Admin、Frontend 检查与构建；浏览器验证从人工评分改为不计分、保存重开、总分更新及答题校验。

本任务不执行生产数据更新、不提交或部署，保留当前工作区其他修改。

## 实现与验证

已实现显式 none、残留分值隔离、schema ordinal/题库 ID/历史快照映射、查看与导出一致显示。Go 判分、考试服务和 HTTP 相关包测试通过；Admin 考试专项、构建通过；Frontend check:all 和 build:h5 通过。隔离浏览器验证选择、总分变化、保存刷新、必填门禁及答案提交。

全量 Backend 仍有既有 Swagger、钉钉配置、审计分类、配置检查及 HTTP 错误边界失败；Admin check:all 仍被用户页面1867/1859行预算阻断。未部署、未修改生产答卷。
