# 钉钉 H5 流程汇总与导出实施计划

1. 为汇总按钮、汇总 API 和导出 API 补权限目录、路由映射、历史迁移及回归测试。
2. 在通用工作流查询模型中增加流程版本、实例集合和发起人可见范围过滤，保持原有个人查询不变。
3. 新增钉钉 H5 工作流汇总服务，集中解析统一数据权限，并对列表、详情和导出复用同一访问校验。
4. 建立与具体文件格式无关的导出文档模型，按实例绑定版本扁平化普通字段、表单组和明细列表。
5. 使用后端标准库实现 PDF、DOCX、XLSX 及批量 ZIP 产物，限制实例数量、格式和总输出大小。
6. 新增汇总接口处理器与路由，保持普通实例详情接口不变。
7. 在 `h5app` 新增独立汇总组件和 API 类型，接入筛选、20/50 分页、当前页选择、只读详情及单个/批量下载。
8. 运行聚焦单元测试、后端全量测试、H5 静态检查和 H5 构建，并对宽屏与窄屏执行页面验证。
