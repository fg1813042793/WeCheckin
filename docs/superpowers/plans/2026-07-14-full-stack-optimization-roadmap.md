# 前后端与管理后台优化路线图

## 背景

当前项目包含 Go 后端、uni-app 客户端和 Vue 3 管理后台。近期已经完成了配置环境变量覆盖、启动初始化安全、项目级检查脚本等优化，但工作区仍有多组未提交实现改动。后续优化需要先稳定工程状态，再处理安全、配置、请求层、权限和体验问题。

## 执行原则

- 每轮只处理一个清晰主题，避免后端、客户端和管理后台的大范围改动混在一起。
- 文档使用中文，重要改动先写设计或实施计划。
- 涉及行为变化时使用测试先行，至少补充能防回归的自动化检查。
- 安全相关问题优先于体验和性能问题。
- 每轮完成后运行 `bash scripts/check.sh` 或对应端的构建/检查命令。

## 当前执行批次

本批次已完成 P0-P2 加固和优化：

1. 保留现有未提交优化，不回滚用户或此前生成的改动。
2. 完成密码散列升级：新密码写入 bcrypt，旧 MD5 登录成功后自动升级。
3. 统一后端默认端口、Swagger、Docker、Compose、Nginx 和静态域名到 `8083`。
4. 新增 `/health`、`/ready`，并为启动 AutoMigrate 增加环境变量开关。
5. 完成管理后台 request 返回类型收口、Vite 手动分包和构建 warning 收口。
6. 移动端 FormRender 接入基础 show/hide/required 逻辑规则。
7. 管理后台入口图标注册从全量导入收敛为受控图标表。
8. Docker 部署补齐日志轮转、`X-Request-ID` 追踪和日志查看脚本。
9. 移动端 FormRender 接入计算字段即时回填。
10. 扩展项目级检查，覆盖端口、健康检查、Docker/Nginx、formkit 逻辑和后台构建配置。
