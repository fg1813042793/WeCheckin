# Admin 登录图片验证码设计

## 行为

- 配置键为 `ADMIN_LOGIN_CAPTCHA_ENABLED`，默认关闭。
- `GET /api/v2/admin/auth/captcha` 返回开关状态；开启时同时返回一次性验证码 ID、Base64 PNG 和 120 秒有效期。
- 登录接口增加 `captchaId`、`captchaCode`。开关开启时先消费并校验验证码，再检查账号密码。
- 验证码为 5 位数字和大写字母，排除易混淆字符，忽略输入大小写。
- 验证码无论正确、错误或后续账号登录失败都不能重复使用。
- 开启状态下 Redis 不可用时生成和登录均安全失败，不允许绕过。

## 前端

- 登录页加载时请求验证码接口；关闭时保持原页面。
- 开启时显示验证码输入框、图片和刷新按钮，登录失败后自动刷新。
- 系统配置的“登录配置/管理员”区域增加图片验证码开关，并复用现有 Setup 保存接口。

## 边界

- 仅影响 Admin 账号密码登录，不影响客户端、钉钉 H5 或 `h5app`。
- 验证码答案不进入响应和日志。
- Redis 仅保存规范化答案摘要，TTL 为 120 秒。
