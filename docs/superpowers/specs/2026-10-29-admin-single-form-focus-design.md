# Admin 表单单层焦点边框设计

## 目标

将 Admin 标准表单控件和题库富文本编辑器的双层蓝色焦点框统一为单层一像素蓝色边框，保持键盘焦点可见，不改变非表单控件的焦点与选中效果。

## 影响范围

- Admin 主内容区的 Element Plus 输入框、文本域、下拉框、数字输入、日期和范围输入。
- Teleport 到 body 的弹窗和抽屉中的标准表单控件。
- 日期与时间选择浮层中的输入控件。
- 题库编辑画布及题目编辑弹窗中的富文本编辑器。

不修改登录页中性焦点样式、组织审批工具栏、流程设计器节点、顶部页签和其他非表单交互状态。

## 实现

- 标准控件聚焦统一使用 `1px` 主色 inset box-shadow。
- 移除 `2px` 外层 focus shadow 和浏览器/组件 outline。
- Teleport 弹层使用 `body .el-overlay` 选择器，主色变量提供 Element Plus fallback。
- 日期选择浮层保留专用选择器，但改为单层边框。
- 题库富文本保留蓝色 border-color，删除外层 box-shadow。

## 验证

- 更新 Admin UI shell 与题库静态检查，禁止标准表单恢复双层阴影。
- 运行 Admin 构建和全门禁。
- 浏览器抽查字典弹窗、用户/配置页面、定时任务弹窗和题库富文本。
