# Admin 审计日志紧凑筛选栏设计

## 目标

操作日志和登录日志筛选栏不再显示控件上方标签，并缩短操作者 ID、IP 地址输入框。

## 实现

- 两个日志页继续共用 `AuditLogFilters.vue`。
- 移除 `label-position="top"` 和筛选项可见 label。
- 输入框、下拉框、日期范围增加 `aria-label`。
- 操作者 ID 宽度为 180px，IP 地址宽度为 220px，时间范围保持约 400px。
- 查询和重置按钮紧跟时间范围。
- 中窄屏继续使用两列和单列响应式布局。

## 验证

- 扩展审计日志静态检查。
- 运行审计日志检查与 Admin 构建。
- 浏览器验证操作日志和登录日志两个页签。
