# 问卷文本导入选项值说明设计

## 背景

Admin 问卷设计器的文本导入解析器已经支持显式选项值，语法为 `A. [选项值] 选项文本`。当前导入弹窗只说明选项以 `A. B. C.` 开头，示例也没有展示显式选项值，用户无法从界面得知这一能力。

## 目标

- 在文本导入弹窗中明确说明显式选项值语法。
- 在占位示例中同时展示普通选项和带显式选项值的选项。
- 保持当前解析规则不变：未填写显式值时继续使用选项字母作为默认值。

## 设计

1. 将工具栏提示更新为同时说明普通格式和显式选项值格式，例如 `A. 选项文本`、`A. [选项值] 选项文本`。
2. 在输入框格式示例中增加一组带选项值的选项，确保用户可以直接照抄语法。
3. 在 `check-survey-designer-ux.mjs` 中加入文本契约断言，要求弹窗保留显式选项值说明和示例。

## 范围

- 修改 `admin/src/views/survey/components/SurveyDesignerTextImportDialog.vue`。
- 修改 `admin/scripts/check-survey-designer-ux.mjs`。
- 不修改 `parseSurveyText`、导入数据结构或后端接口。

## 验证

1. 先运行问卷设计器 UX 检查，确认新增契约在文案修改前失败。
2. 完成文案修改后再次运行该检查，确认通过。
3. 运行 `cd admin && npm run check:all`。
4. 使用浏览器打开问卷设计器文本导入弹窗，检查提示完整显示、示例可读且不会遮挡操作区域。
