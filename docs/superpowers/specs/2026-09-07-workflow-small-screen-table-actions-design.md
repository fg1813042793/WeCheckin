# 流程小屏表格与操作按钮设计

## 目标

- PC 小屏幕下，流程中心各记录列表和发起审批页的历史记录不裁切任何表格列。
- 横向滚动时“操作”列保持在右侧，用户始终可以进入详情或办理任务。
- 流程详情底部操作按钮统一为 `96px`，减少短文案两侧空白。

## 设计

`WorkflowRecordTable` 在桌面布局下改为横向滚动容器，表头和数据行使用同一份网格列定义，操作列表头与单元格使用 `position: sticky` 固定到右侧。`900px` 以下继续使用现有卡片布局，不增加横向滚动。

`WorkflowStartPage` 的历史记录保留现有横向滚动和 `960px` 最小宽度，并将操作列固定到右侧。固定单元格使用对应的表头或行背景，避免滚动内容从其下方透出。

`WorkflowDetailPanel` 的底部申请操作区由 `120px` 网格列调整为 `96px`；按钮内部仍保持 `6px` 水平内边距和不换行，兼容“再次提交”“申请修订”等四字文案。

## 验证

- 契约脚本检查横向滚动、固定操作列和 `96px` 按钮宽度。
- 执行 H5App TypeScript、针对性 ESLint、流程模块契约和生产构建。
- 使用浏览器验证 1024、1200、1366 宽度下列完整可滚动、操作列可见且按钮留白收紧。
