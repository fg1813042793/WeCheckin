# 题库三栏工作台设计

## 目标

将 Admin 题库管理从“表格 + 大弹窗编辑”改为常驻三栏工作台，提高连续维护同一题库内多道题目的效率。

## 范围

- 保留 `/question-bank` 路由和现有问卷题库、考试题库 API。
- 保留顶部问卷/考试题库切换、导入和导出。
- 沿用 `category` 字段作为题库名称，不新增题库表、迁移或后端接口。
- 不增加题库重命名、题库删除、拖拽排序和批量移动能力。

## 布局

- 顶部工具栏：返回/标题、问卷题库与考试题库切换、导入、导出、保存状态、立即保存。
- 左栏上部：全部题目、未分类和现有分类；左栏下部：当前分类的题目搜索、题型筛选和题目列表。
- 中栏：题目标题、选项、字段、矩阵等核心内容编辑；支持编辑、预览、JSON 三种模式。
- 右栏：题型、所属题库、标签、必填、只读、提示语、说明和题型专属属性；考试模式额外显示分值、正确答案和解析。

标准桌面常驻三栏；窄屏桌面可折叠左右栏；小于 768px 显示桌面端编辑提示。

## 组件边界

- `QuestionBank.vue`：页面状态和 API 协调器。
- `QuestionBankNavigator.vue`：题库与题目导航。
- `QuestionEditorCanvas.vue`：内容编辑、预览和 JSON 模式。
- `QuestionPropertiesPanel.vue`：通用属性和考试属性。
- `QuestionRichEditorDialog.vue`：继续复用高级富文本编辑。

旧的 `QuestionBankTable.vue`、`QuestionEditorDialog.vue` 和独立预览抽屉不再作为主交互入口。

## 数据流

1. 切换问卷/考试范围后重置分类、搜索、分页和当前题目。
2. 选择分类后调用现有列表接口加载当前分类题目。
3. 选择题目时复制服务端数据为编辑草稿，列表数据不被直接修改。
4. 保存成功后以当前草稿更新左侧题目摘要，不强制刷新整个页面。
5. 新增题目默认使用当前分类，首次手动保存成功后进入已有题目编辑状态。

## 保存与切换

- 新增草稿不自动创建，首次必须手动保存。
- 已有题目修改后延迟 800ms 自动保存。
- “立即保存”和 `Ctrl/Cmd + S` 立即提交。
- 状态包含：未保存、保存中、已保存、保存失败。
- 切换题目、分类或范围前刷新待执行自动保存；保存失败时保留草稿并阻止切换，允许重试、放弃或取消。

## 权限和异常

- 查看权限允许浏览；无编辑权限时编辑区只读。
- 新增、编辑、删除按钮分别使用对应菜单权限，后端 API 权限继续作为安全边界。
- 列表失败显示错误与重试，不冒充空数据。
- 保存失败保留草稿；目标被删除时刷新列表并清空当前选择。
- 删除当前题目后选择相邻题目；无题目时展示新增入口。

## 验证

- 静态契约锁定三栏组件、移除弹窗主编辑入口、混合保存状态和小屏提示。
- 运行题库聚焦检查、Admin 全量检查和生产构建。
- 浏览器检查 1440px、1024px、390px，并冒烟新增、编辑、自动保存、手动保存、切换保护、删除、范围切换、预览、JSON 与权限禁用。
