# 钉钉 H5 流程汇总与导出设计

## 目标

在钉钉 H5 的单个流程页面中，于“流程图”后增加“汇总”页签。汇总面向被授权的流程管理人员，展示该流程定义全部已发起实例，并支持查看详情以及导出 PDF、Excel、Word。

本功能只扩展通用工作流和 `h5app`，不改变现有“我的申请”“我的待办”“已处理”“抄送我的”的访问语义，也不修改绩效业务流程。

## 权限模型

- “汇总”页签由按钮权限 `dingtalk_h5:button:workflow:summary` 控制，父权限为 `dingtalk_h5:menu:workflow`。
- 汇总列表和管理详情使用 API 权限 `dingtalk_h5:api:workflow:summary`。
- 单个和批量导出使用 API 权限 `dingtalk_h5:api:workflow:export`。
- 后端接口是最终安全边界，前端隐藏按钮不能替代接口权限校验。
- 新权限仅注册，不自动授予已有角色或用户。

管理人员需要同时具备流程菜单、汇总按钮、所需 API 权限和数据权限。只有汇总权限但没有数据权限时，列表为空。

## 数据范围

汇总数据按流程发起人应用统一 `data:*` 权限：

- `data:all`：可见所有发起人。
- `data:dept`：可见当前用户所属部门及子部门的发起人。
- `data:self`：仅可见本人发起的实例。
- `data:custom`：可见授权部门及子部门的发起人。
- `data:extra`：在基础范围之外追加指定人员和指定部门及子部门。
- 没有有效数据范围：不可见任何实例。

部门判断读取用户当前组织关系，不把部门成员固化成快照。列表、详情、单个导出和批量导出均执行同一范围校验；批量接口不能通过伪造实例 ID 越权。

## 查询与页面

汇总固定在当前选中的流程定义下，覆盖该定义的全部历史发布版本，但不包含草稿。每行显示实例实际绑定的流程版本。

筛选条件：发起人用户名、状态、流程版本、发起时间范围、完成时间范围。

列表列：选择框、申请编号、发起人、操作人、流程版本、状态、发起时间、完成时间、操作。

默认按发起时间倒序，分页大小支持 20 和 50。批量选择仅保留当前页，翻页后清空，支持选择当前页全部记录。

## 接口

- `GET /api/v2/dingtalk/h5/workflows/summary/definitions`
  - 返回全部已发布流程定义，使只有汇总权限、但不在流程发起范围内的管理人员也能进入对应流程。
- `GET /api/v2/dingtalk/h5/workflows/summary/definitions/:id`
  - 返回汇总页和流程图使用的已发布定义，不授予流程发起能力。
- `GET /api/v2/dingtalk/h5/workflows/summary/instances`
  - 查询参数包含 `definitionId`、筛选条件、`page`、`pageSize`。
  - `definitionId` 必填，`pageSize` 最大 50。
- `GET /api/v2/dingtalk/h5/workflows/summary/instances/:id`
  - 返回只读管理详情，复用实例绑定版本的表单和流转记录装配。
- `GET /api/v2/dingtalk/h5/workflows/summary/export`
  - 参数包含 `definitionId`、`instanceIds` 和 `format`。
  - `instanceIds` 最多 50 个，去重后必须全部属于当前流程定义并位于调用者数据范围内。
  - `format` 仅允许 `pdf`、`xlsx`、`docx`。

## 导出规则

每份导出内容包括：

- 流程名称、申请编号、实例绑定版本。
- 发起人、操作人、状态、发起时间、完成时间。
- 按绑定发布版本还原的完整表单字段和值，包括表单组和明细列表。
- 审批记录附录，包括节点、处理人、动作、意见和处理时间。
- 附件只输出文件名和访问地址，不嵌入附件二进制。
- 不输出流程图图片。

单个实例按所选格式直接下载。批量 PDF、Word 返回 ZIP 且每个实例一个文件；批量 Excel 返回一个工作簿且每个实例一个工作表。文件名、ZIP 项和工作表名需要清理非法字符并保证唯一。

首版使用同步导出，单次最大 50 个当前页实例，并设置总产物大小上限，避免请求无限占用内存和 HTTP 服务资源。超过边界时明确拒绝，不在请求内排队处理跨页全量导出。

## 兼容与错误

- 历史实例始终使用其 `definitionVersion` 对应的发布定义和 `formData`，不读取当前草稿覆盖历史表单。
- 普通实例详情接口仍按本人发起、本人处理或抄送参与人校验；管理详情使用独立接口。
- 实例不存在、流程定义不匹配、任一实例越权或格式不支持时，导出整体失败，不返回部分文件。
- 导出日志只记录实例 ID、数量、格式和结果，不记录表单值或附件地址。

## 验证

- 权限目录、路由权限映射和迁移测试。
- 数据范围的 all、dept、self、custom、extra 和无权限测试。
- 列表过滤、最大分页、跨定义和伪造 ID 拒绝测试。
- PDF 文件头与分页、DOCX/XLSX ZIP 结构、批量 ZIP/多工作表和特殊字符测试。
- H5 权限可见性、筛选、分页选择、详情只读和下载交互检查。
- 执行后端相关测试、`h5app` 的 lint、type-check、工作流专项检查和 H5 构建。
