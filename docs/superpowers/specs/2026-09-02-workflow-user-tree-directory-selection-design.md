# 流程用户树目录选择设计

## 目标

所有使用 `WorkflowUserTreePicker` 的多人选择场景支持勾选部门目录；单人选择场景仍只能选择具体用户。

## 行为

- 多人模式勾选部门时，将该目录下当前可见的所有用户加入选中结果。
- 取消部门时，从选中结果中移除该目录下的所有用户。
- 用户同时属于多个部门时按用户 ID 去重。
- 搜索只影响展示，目录操作仍以完整子树为准。
- 对外继续输出用户 ID 数组，不改变后端契约。

## 影响范围

- 定时任务的流程发起人。
- 后台为多名用户分别发起流程。
- 流程设计器的“额外允许用户”。

单人代发起不支持选择目录，避免从多个用户中隐式选取一人。
