# Admin 左侧菜单隐藏字段设计

## 目标

后台权限管理中的 Admin 目录和菜单支持“左侧菜单隐藏”配置。开启后不出现在后台左侧导航，但权限授权、路由守卫、直接 URL 访问和权限管理树保持有效。

## 数据契约

- `permissions` 新增 `permission_hidden tinyint NOT NULL DEFAULT 0`。
- API 字段名为 `hidden`：`1` 隐藏，`0` 显示。
- 只对 `permission_platform=admin` 且类型为 `directory/menu` 的左侧菜单构建生效；其他平台和权限类型保存字段但不改变现有运行时行为。

## 菜单构建

后端按现有权限和状态返回包含 `hidden` 标记的完整菜单树，供路由授权、直接访问和页面缓存判断使用。Admin 布局另外派生左侧导航展示树，并在该展示树中递归移除隐藏节点及其后代，不能把子节点提升到根级。

权限 key 获取不读取隐藏状态，因此按钮/API 权限、角色授权和直接路由访问不受影响。

## 管理界面

- 后台菜单权限列表增加“左侧菜单”列，显示“显示/隐藏”。
- 编辑弹窗在 Admin 目录和菜单类型下显示“左侧菜单隐藏”开关。
- 新增权限默认显示；编辑时回显；保存后刷新菜单配置。

## 验证

- 模型、迁移、handler、service 和运行时菜单过滤测试。
- Admin 静态契约、TypeScript 构建和浏览器保存/刷新验证。
