# Admin 用户禁止权限默认折叠设计

## 目标

- 用户管理的新增、编辑表单中，“禁止权限”区域默认收起，减少权限表单的初始高度。
- 用户可通过“禁止权限”标题右侧的“展开/收起”按钮查看或隐藏现有四棵禁止权限树。
- 折叠只改变展示状态，不清空勾选、不改变保存数据，也不修改接口和权限语义。

## 交互设计

沿用“用户扩展应用权限”现有的折叠分隔栏样式，在“禁止权限”分隔标题右侧增加箭头图标和“展开/收起”按钮。

“额外授权”面板继续保持当前展示方式。“禁止权限”的客户端菜单、钉钉 H5 菜单/按钮、客户端接口和钉钉 H5 接口四个面板作为一个整体展开或收起，不增加单面板折叠状态。

每次打开新增或编辑用户表单时，禁止权限区域都重置为收起。用户在当前表单会话中展开后，折叠状态只持续到该表单关闭；再次打开表单仍从收起状态开始。

## 实现边界

- 在 `admin/src/views/user/index.vue` 增加独立的禁止权限展开状态，默认值为 `false`。
- 新增和编辑入口统一重置该状态，避免上一次打开表单的展示状态泄漏到下一次。
- 使用 `v-show` 控制两列禁止权限面板，保留已挂载权限树及其勾选状态。
- 复用现有折叠标题、按钮和箭头样式，不新增依赖、不改变 API、DTO 或后端逻辑。

## 验证

- 先扩充 `admin/scripts/check-user-list-ui.mjs`，断言独立折叠状态、默认收起、打开表单时重置以及模板展开绑定；修改页面前验证检查失败。
- 完成页面改动后运行 `npm run check:user-list-ui`，确认局部契约通过。
- 运行 `npm run check:all` 和 `git diff --check`，确认 Admin 静态检查、类型构建及格式检查通过。
- 浏览器验证新增和编辑用户表单默认收起，展开后四个禁止权限面板完整显示，勾选值在收起和再次展开后保持不变。
