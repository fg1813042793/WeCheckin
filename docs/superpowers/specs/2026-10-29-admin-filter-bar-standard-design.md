# Admin 列表筛选栏统一设计

## 目标

统一 Admin 列表页顶部筛选栏：容器使用 `12px 14px` 内边距，查询与重置紧跟最后一个筛选项，筛选项不显示顶部标签而使用 placeholder 表达含义。

## 适用范围

- 适用于列表页、记录页和管理页顶部用于查询数据的筛选区域。
- 不适用于新增/编辑弹窗、详情表单、设计器属性面板、树节点内部搜索等非列表筛选场景。
- 不改变接口参数、查询逻辑、权限判断和页面级新增/导出/刷新操作。

## 组件职责

- `AdminFilterActions` 统一“查询、重置”的顺序、尺寸、间距、加载态和表单提交行为。
- `AdminSearchBar` 将筛选项和操作组放在同一 flex 流中，使用 `12px 14px` 内边距并在窄屏自然换行。
- 旧式 `admin-toolbar` 页面继续保留原容器，但筛选控件和 `AdminFilterActions` 必须位于同一个 `admin-toolbar__left` 中；页面级操作仍放在独立工具栏或右侧区域。

## 标签与无障碍

- 列表筛选项不显示 `el-form-item` 顶部 label。
- 输入框、选择器和日期控件使用明确 placeholder。
- placeholder 无法完整表达含义时补充 `aria-label`，不能以移除标签为代价丢失无障碍名称。

## 响应式

- 桌面端控件保持紧凑固定宽度，动作组紧跟最后一个筛选项。
- 空间不足时筛选项和动作组按整体自然换行，不把动作组单独推到容器右侧。
- 小于 768px 时筛选控件占满一行，动作组保持内容宽度并左对齐。

## 验证

- 静态契约检查覆盖共享组件布局、动作顺序、筛选栏内边距、可见标签和右侧查询/重置回归。
- 运行 Admin 相关专项检查、TypeScript/Vite 构建和浏览器桌面/窄屏冒烟。
