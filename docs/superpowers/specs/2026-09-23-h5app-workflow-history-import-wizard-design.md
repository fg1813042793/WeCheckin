# H5App 历史表单导入三步向导设计

## 目标

将历史表单导入弹窗从同屏展示“选择、配置、预览”三段内容，调整为一次只展示一个步骤的三步向导，降低页面高度和信息密度。

本次只调整 `WorkflowHistoryImportDialog.vue` 的交互和布局，不修改历史实例查询范围、字段兼容规则、覆盖规则、权限或导入补丁格式。

## 步骤状态

弹窗内部新增步骤状态：

```text
select -> configure -> preview
```

- `select`：选择历史申请。
- `configure`：设置全部导入或字段映射，以及是否覆盖已有内容。
- `preview`：查看实际导入、覆盖、保留和跳过结果。

弹窗打开时始终从 `select` 开始，并清空上一次打开留下的临时状态。

## 选择步骤

选择页只展示标题搜索、状态筛选、历史申请列表和分页。

用户点击历史申请后：

1. 保持当前列表可见并显示详情加载状态。
2. 调用现有 `getWorkflowInstance`。
3. 详情加载成功后初始化全部导入映射和手工映射建议。
4. 自动切换到 `configure`。
5. 详情加载失败时停留在 `select`，展示错误和重试入口。

重新返回选择页时保留已选择的记录，用户可以改选其他历史申请。

## 配置步骤

配置页只展示：

- 当前来源申请摘要和版本。
- “全部导入 / 字段映射”切换。
- “覆盖已有内容”开关。
- 全部导入字段数量或手工映射行。

底部操作为“上一步”和“下一步”。下一步进入预览；映射存在重复、无效或来源详情缺失时禁止进入。

## 预览步骤

预览页只展示统计和字段级预览，不重复展示历史列表或映射编辑器。

底部操作为“上一步”和“确认导入”。没有任何可导入或可覆盖字段时，确认按钮保持禁用，但允许返回配置修改。

## 顶部与关闭按钮

标题区域显示：

- 主标题“导入历史表单”。
- 当前步骤标题。
- 紧凑文本“步骤 1/3”“步骤 2/3”或“步骤 3/3”。

不同时展示三个步骤标题和三段内容。

关闭按钮改为固定 `32px × 32px` 的图标按钮：

- 无大面积默认按钮边框。
- 默认透明背景，悬停和键盘聚焦时显示浅灰背景与清晰焦点环。
- 使用 `u-icon close`，提供 `title="关闭"`、`role="button"`、`tabindex="0"` 和 Enter/Space 键盘关闭。

## 响应式

PC 继续使用居中弹窗，移动端继续使用底部全宽弹层。标题和底部操作固定，只有当前步骤内容区滚动。

移动端配置页的映射行维持现有紧凑布局，底部按钮平分可用宽度并保留安全区。

## 验证

- 结构检查确认三个步骤使用互斥渲染。
- 选择详情成功后自动切换配置步骤。
- 配置页和预览页可以往返，映射与覆盖设置不丢失。
- 关闭按钮具有固定尺寸、可访问标签和键盘事件。
- 运行 H5App 专用历史导入检查、相关文件 ESLint、类型检查和 H5 构建。
