# Admin 问卷考试搜索按钮内联设计

## 目标

考试管理和问卷管理的“重置、查询”按钮紧跟筛选输入控件，不再靠搜索栏最右侧。

## 实现

- 两个页面关闭 `AdminSearchBar` 默认 actions 区域。
- 在字段插槽末尾渲染共用 class 的重置、查询按钮组。
- 查询按钮使用表单 submit，保留回车搜索行为。
- 宽屏按钮与筛选控件同一行；空间不足时按字段顺序换行。
- 移动端按钮组左对齐。
- 不修改其他 Admin 搜索栏。

## 验证

- 更新 P2 UI 静态检查，要求两个页面使用内联 actions。
- 运行 P2 UI 检查、Admin 构建和浏览器宽屏/窄屏验证。
