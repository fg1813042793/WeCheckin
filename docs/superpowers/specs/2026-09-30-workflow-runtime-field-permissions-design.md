# 流程字段权限运行时配置设计

字段权限从发布版本结构中拆出一份独立运行时配置。Admin 保存字段权限后更新 `workflow_definitions` 上的权限 JSON 与修订号，不增加流程发布版本。后端加载任意发布版本或运行中实例时，按稳定节点 ID 覆盖匹配节点的字段权限；旧版本不存在的节点或字段自动忽略。

运行时配置影响该定义下所有运行中实例和未来实例。发布版本仍保留当时结构快照，用于审计；字段权限单独记录修订号。仅字段权限变化不构成待发布差异。

新增字段：`definition_field_permissions_json`、`definition_field_permissions_revision`。Admin 字段权限页面明确提示“保存后立即影响运行中和未来实例”。

验证覆盖：配置编解码、防御性克隆、旧版本节点/字段过滤、迁移契约、保存修订号、运行中实例详情覆盖、发布差异忽略和 Admin 构建。
