# 考试列表答卷数量展示设计

## 目标

在后台考试列表的卡片视图和列表视图中展示每场考试已经提交的答卷数量。

## 统计口径

- 字段名称：`responseCount`。
- 统计 `exam_record` 中对应考试且 `exam_r_status >= 1` 的记录。
- `status = 0` 的进行中考试记录不计入。
- 同一用户多次提交按多份答卷统计。
- 公开或匿名考试使用同一口径，不依赖用户身份、设备或 IP 去重。

## 后端设计

考试列表仍使用现有 `/api/v2/admin/exams` 接口。列表服务取得当前页考试后，收集考试 ID，通过一次按 `exam_r_exam_id` 分组的聚合查询获得当前页答卷数量，避免逐场考试查询。

管理端考试列表 DTO 增加 `responseCount`。没有答卷的考试返回 `0`，不省略字段。

聚合查询只处理当前页考试 ID，并保持现有管理员数据范围过滤和考试列表分页行为不变。

## Admin 展示

- 卡片信息区在“最长交卷”“答题次数”之后增加“已交答卷”，值显示为 `N 份`。
- 列表视图增加“答卷数”列，值显示为 `N 份`。
- 现有“查看答卷”和“统计”操作入口保持不变。
- 加载、筛选、翻页和复制考试行为保持不变。

## 验证

- 后端测试覆盖：空列表、零答卷、进行中记录排除、已提交和已批改记录计入、当前页批量聚合。
- Admin 契约检查覆盖卡片和列表视图对 `responseCount` 的展示。
- 运行后端相关测试、Admin 考试管理检查、Admin 构建和浏览器卡片验证。
