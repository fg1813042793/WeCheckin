# 工作流通知配置说明弹窗设计

## 目标

在流程设计器的审批、办理、抄送和通知节点配置中增加通知说明入口，让设计人员无需离开当前抽屉即可了解通知渠道、模板写法、可用占位符和发送长度限制。

## 交互

- 在通知配置区标题右侧、通知开关左侧增加问号图标按钮。
- 图标提供“通知消息配置说明”悬停提示。
- 点击后打开 `el-dialog`，使用 `append-to-body`，避免被后台固定导航或节点抽屉遮挡。
- 关闭弹窗后保留节点当前编辑内容，不修改流程定义。

## 弹窗内容

- 配置说明：选择渠道、编辑标题和正文，发布后在任务到达或节点触发时渲染。
- 占位符表格：`workflowName`、`nodeName`、`starterName`、`instanceId`、`taskId`。
- 示例：展示模板和渲染后的标题、正文。
- 限制：模板标题最多 256 字、正文最多 2000 字；发送快照标题最多 64 字、正文最多 1000 字。
- 安全边界：不支持读取任意表单字段或流程变量。

## 验证

- 静态回归检查锁定图标、弹窗、`append-to-body`、五个占位符及示例。
- 运行工作流树检查和管理端生产构建。
- 在浏览器中验证说明图标可点击、弹窗位于抽屉上方且内容无溢出。
