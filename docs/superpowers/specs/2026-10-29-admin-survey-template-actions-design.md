# Admin 问卷通知模板操作布局设计

## 目标

问卷通知模板列表的编辑、删除按钮保持单行横向排列，页头刷新操作改为统一的圆形图标按钮。

## 实现

- 操作列使用现有 `admin-table-actions` 容器，不新增重复的按钮布局样式。
- 操作列宽度保证两个文字按钮能够稳定并排。
- 刷新按钮使用 Element Plus 圆形图标按钮，保留 loading、title 和原加载事件。
- 不改变权限、编辑、删除和刷新业务行为。

## 验证

- 扩展问卷通知模板静态检查。
- 运行页面检查和 Admin 构建。
- 浏览器验证操作按钮不换行，刷新按钮只显示图标。
