# 流程发起页单一卡片布局设计

## 目标

将 H5/PC 共用的流程发起页表单主体放入一张完整卡片，增强表单与页面背景的边界，同时避免按字段或表单组生成多层卡片。

## 页面结构

- 顶部“发起审批、历史记录、草稿箱、流程图”导航保持不变。
- `WorkflowRuntimeForm` 外增加一个语义明确的表单卡片容器。
- 卡片在 PC 端使用白色背景、细边框、轻阴影和紧凑内边距。
- 移动端保留卡片边界，但缩小边距和内边距，避免压缩表单输入区域。
- 明细列表、表单组等现有内部结构保持不变，不额外创建分组卡片。

## 操作区

- 底部操作区继续保持独立和吸底行为，避免长表单滚动后找不到操作入口。
- 按钮顺序由“取消、保存草稿、提交申请”调整为“取消、提交申请、保存草稿”。
- 按钮权限、加载态、禁用条件和点击处理逻辑保持不变。

## 兼容性

- 不修改流程定义、表单数据、草稿和提交接口。
- 不修改绩效管理页面及其他业务模块。
- PC 与移动端共用相同 DOM 顺序，响应式样式只调整尺寸和间距。

## 验证

- 结构检查覆盖单一卡片容器和操作按钮顺序。
- 运行 H5 工作流专项检查、ESLint、TypeScript 检查和 H5 生产构建。
