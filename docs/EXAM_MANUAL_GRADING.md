# 考试答卷人工批改

考试记录列表及“查看答卷”弹窗提供批改入口。有批改权限时，待批改答卷显示“批改/开始批改”，已完成答卷显示“查看批改结果”。进行中的答卷不可批改。

## 使用方式

在批改页核对考生作答、题目材料和参考答案，为全部人工题输入 0 至各题满分之间的整数分数；0 分需要明确填写，不能留空。自动评分题只读。页面预览总分及通过结果，提交确认后由服务端重新计算并保存最终结果。提交失败会保留输入，提交成功后只读，不能重复改分。

遇到答卷版本变化可使用“重新加载答卷”。成功重新加载后保留仍属人工题、且分值仍有效的原评分与评语，并要求明确核对最新题目、答案和分值后才能提交；若已由其他人完成，则转为结果只读。

保存内容包括逐题得分、总分、通过状态、批改人 ID、批改时间和最长 1000 字的人工评语。评语随答卷结果返回。已提交答卷不能再通过草稿保存或再次交卷覆盖评分。

## 接口和权限

- `GET /api/v2/admin/exams/{id}/records/{recordId}/grading`：获取批改上下文，包含版本、题目、作答、参考答案、已得分、满分和可批改状态。
- `POST` 同路径：JSON `{expectedVersion, scores:[{questionId,score}], comment}`。所有待人工题必须恰好出现一次，不能提交客观题或其他题目。
- 菜单按钮：`admin:menu:exam:record-grade`；API 权限：`admin:api:exam-record:grade`，业务权限码 `exam-record:grade`。页面与调用端同时检查两项权限；后端再校验考试数据范围及答卷归属。
- 更新在事务内锁定答卷，校验 `expectedVersion` 与待批改状态，防止多人覆盖和重复提交。评分只更新当前答卷，不新增提交计数，不重发交卷通知；审计动作是 `exam / grade`。

## 题目快照和历史兼容

新交卷保存私有题目定义、参考答案和及格分快照，包括说明、矩阵行列、填空项、选项及配图链接。批改页展示这些材料和安全的配图链接，评分上限始终取交卷时的逐题评分结果。私有快照不包含在普通 `ExamRecord` JSON 中，仅授权的后台批改接口提供参考答案。

历史答卷没有题目快照时，页面明确提示其题目与参考答案按当前配置展示，管理员应核对是否修改过题目。仍使用已存逐题满分约束评分；题目或逐题评分资料缺失时禁用提交，不伪造历史快照。原有数组与整卷对象两种评分结果格式均兼容。

## 升级

先按项目迁移流程执行 `backend/migrations/20261031140000_add_exam_manual_grading.sql`，再更新后端和 Admin。迁移幂等添加私有快照、批改人、时间和评语列，登记权限，并仅为已有对应考试编辑 allow 授权的主体补齐批改权限；目标已有授权、deny 或停用记录不被覆盖。重新登录刷新权限后可见入口。

迁移不回填历史题目快照，不会自动批改任何答卷。本次开发未执行生产迁移或生产批改。
