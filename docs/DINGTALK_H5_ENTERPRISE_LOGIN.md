# 钉钉 H5 企业切换和账号绑定

钉钉工作台 H5 使用 `h5app/`。每个企业的实际入口应携带自己的 `corpId`（兼容 `corpID`、`corp_id`）。前端优先读取 URL 普通查询参数，再读取 hash 查询参数；缺少标识时沿用公开配置的默认企业。切换钉钉组织但复用完全相同且没有正确企业参数的入口，无法仅靠页面判断实际组织。

## 登录与退出

- 退出清除本地会话、权限、绑定票据、旧错误、免登尝试状态和业务页签，停留在登录页，不立即自动登录回来。
- 钉钉环境的登录页提供“钉钉重新登录”；绑定页的“重新免登”也允许重新获取授权码和绑定票据。
- 页面重新显示、获得焦点、从后台恢复或发生 URL 导航时检查企业标识。企业变化会重新认证；同企业的普通焦点事件不重复发起免登。
- 登录成功时保存企业标记 `DT_H5_TOKEN_CORP_ID`。同企业缓存可以恢复；企业不一致时丢弃旧缓存。升级前未带企业标记的钉钉会话会重新认证一次；普通浏览器仍支持原有密码登录。
- 旧企业延迟返回的免登、绑定、密码登录和 bootstrap 结果不更新新企业状态。通用请求和文件上传也会核对发起请求时的会话，防止旧资料保存响应覆盖新用户，或旧上传响应清除新会话。
- 切换期间尚在准备的上传文件不会使用新企业会话发送；普通菜单页签、动态业务页签一并清理，保留菜单布局偏好。

该企业标记只管理客户端的认证上下文，不是服务端租户授权凭证。业务权限仍由后端当前系统用户的权限与数据范围校验。

## 何时显示绑定页

`POST /api/v2/dingtalk/h5/sso-login` 成功获取企业身份后，若没有绑定且允许自助绑定，后端返回业务码 `10020` 及绑定票据，页面才显示“绑定并登录”。提交到 `/bind-self` 成功后才创建绑定并进入系统。

企业应用凭据错误、授权码错误或网络失败会显示错误和重新登录入口，不会被当作未绑定。普通账号密码登录不会创建钉钉企业绑定。需在“钉钉配置 → 企业应用”修正对应企业的配置，再重试免登。

## 验证

`cd h5app && pnpm check:dingtalk-auth-context` 覆盖退出与重试、企业缓存、同页面企业切换、旧响应隔离、绑定票据归属、初始化去重和浏览器密码登录兼容。发布前还需运行 H5 静态检查、构建，并在真实钉钉企业入口验证。
