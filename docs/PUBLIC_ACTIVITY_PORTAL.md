# 公共问卷与考试入口

公共页面地址为 `/public/activities`；后台配置入口为“公共页面管理”（`/public-portal`）。公开来源不会自动出现在页面上，必须由管理员选择并上架。

## 上线步骤

1. 更新 Backend 和 Admin。`/public/activities` 与原 `/sf`、`/sf1`、`/ef`、`/ef1` 填写页使用同一 Admin 前端部署，Web 服务器需支持这些地址刷新后回退 `index.html`。
2. 在维护窗口按现有维护流程执行 `backend/init.sh`，应用 `backend/migrations/20261103090000_create_public_activity_portal.sql`。主服务不自动建表；本次开发没有执行生产迁移。
3. 给负责配置的管理员分配下表权限，保存后重新登录。迁移只为已有启用的保留超级管理员角色添加初始授权，不扩大普通角色权限。
4. 打开“公共页面管理 → 页面设置”，填写页面标题、简介和 Logo 地址。公共链接会自动使用当前访问站点。
5. 在“展示内容”添加所需公开问卷/考试，设置展示文案、排序和上架状态。
6. 点击“预览已保存内容”核对，再开启公共入口并保存。复制公共链接用于对外投放。

| 用途 | 权限 Key |
| --- | --- |
| 管理页面入口 | `admin:menu:public-portal` |
| 编辑按钮 | `admin:menu:public-portal:edit` |
| 配置、候选与预览接口 | `admin:api:public-portal:list` |
| 保存、上下架和移除接口 | `admin:api:public-portal:edit` |

公共域名无需配置。后台显示和复制的公共链接取当前页面站点地址，加 `/public/activities`；公开接口返回 `/sf/...`、`/sf1/...`、`/ef/...` 或 `/ef1/...` 根相对路径，浏览器以当前站点补全后用于直接进入、复制和二维码生成。保留当前地址的协议、主机和端口，支持本地、局域网及公网部署，且不将 API 服务地址用作网页地址。

旧 `public_base_url` 数据库列保留兼容，但不再用于生成链接；旧客户端提交的 `publicBaseUrl` 被忽略，新页面不显示或提交此字段。无需为此次调整增加数据库迁移。

Logo 可使用站内绝对路径或 HTTP(S) 地址，留空显示默认标识。所有页面文案均为纯文本展示。页面默认关闭；保存时不再要求填写域名，管理员可直接开启或预览。

## 内容配置与展示

- 候选显示管理名称、显示名称和 ID，只查询当前管理员数据范围内、已发布且公开的来源。保存时再次校验范围，不能通过手工修改来源 ID 越权添加。
- 展示标题和简介留空时，实时跟随来源显示名称和简介；显示名称未配置时回退原标题。源简介中的 HTML 转为纯文本。
- 公开卡片同时显示来源的管理名称和问卷/考试编号，管理名称实时跟随来源更新，用于区分同名内容。搜索支持显示名称、管理名称、简介和编号；二维码预览同步显示管理名称与编号。
- 分类标签实时跟随来源的 `category`：例如考试中设置“面试题”，公共卡片、编号文案、二维码预览、后台展示项及来源选择会同步显示“面试题”；分类为空时回退“问卷”或“考试”。公共页顶部提示和筛选按钮由当前展示项的分类去重生成，按实际分类筛选，支持与关键词搜索组合使用；不同来源类型使用相同分类名称时归入同一筛选项。刷新后分类被移除或改名时自动回到“全部”，后台配置的页面标题保持原值。来源的 `kind` 和填写链接仍使用原问卷/考试类型。公开、预览、后台展示项和候选接口均返回只读 `category`，无需在公共入口重复配置或重新上架，也不新增数据库列。
- 问卷和考试各自按类型加 ID 唯一，最多 200 项；排序小值在前，相同时按展示项 ID 排列。
- 源被删除、停用、改为登录可见/部门限定或配置无效时，公共接口自动过滤，后台注明原因。失效来源可由有权管理员下架或移除；已删除来源允许创建者或超级管理员清理展示配置。
- 移除仅删除入口展示记录，不删除问卷、考试或答卷。
- 未开始内容可展示和下载二维码，按钮标记“尚未开始”；已结束内容默认隐藏，也可配置保留“已结束”卡片。
- 开始/结束时间、密码、登录要求、参与次数等仍由原问卷/考试填写和提交接口执行。公开入口不建立答题会话，也不返回题目、答案、密码或原 settings JSON。
- 问卷链接使用 sf/sf1，考试使用 ef/ef1，跟随来源的受支持填写模板；不采用来源任意自定义外链，所有参与链接均解析到当前站点。

## 二维码与预览

二维码在浏览器本地生成，按需加载，不访问第三方二维码图片服务。下载为带标准留白的黑白 1024×1024 PNG，文件名含类型、来源 ID 和管理名称（管理名称缺失时使用展示标题）。手机可放大图片后长按保存；也可直接进入或复制填写链接。

预览地址 `/public/activities?preview=1` 仅在明确的预览模式下使用管理员凭据读取已保存配置，仍经过后台权限校验，只绕过页面总开关。普通公共访问仅请求匿名接口，不读取或发送管理员 token。

公共接口和配置读取使用 `Cache-Control: no-store`。已经下载的二维码是原填写链接；移除展示项不会销毁已分发图片。如需阻止继续参加，应在原问卷/考试中停用或调整可见性。

## API

| 方法 | 地址 | 用途 |
| --- | --- | --- |
| GET | `/api/v2/public/activities` | 匿名公共内容 |
| GET | `/api/v2/admin/public-portal` | 页面配置与展示项 |
| PUT | `/api/v2/admin/public-portal/settings` | 保存页面设置 |
| GET | `/api/v2/admin/public-portal/options` | 按类型搜索来源 |
| GET | `/api/v2/admin/public-portal/preview` | 预览已保存内容 |
| POST | `/api/v2/admin/public-portal/items` | 添加展示项 |
| PUT | `/api/v2/admin/public-portal/items/{id}` | 修改展示项 |
| DELETE | `/api/v2/admin/public-portal/items/{id}?version=...` | 移除展示项 |

设置与展示项独立使用 `version` 乐观锁，冲突返回“配置已更新，请刷新后重试”。所有写操作使用事务；展示项总量通过锁定页面配置行串行核对。请求校验类型、长度、分页、来源范围及链接格式。未知内部错误只记录到服务日志，不向匿名访客暴露迁移信息或数据库细节。
